# AromaMaster 製品仕様（Planner Agent 出力）

## ブリーフ
NVC（観察・感情・ニーズ・リクエスト = OFNR）の流れで「いまの自分」を言葉にし、
科学的根拠レベル付きの精油データから、デバイス別に **容器容量・無水エタノール量・精油量（mL/滴）・メーカーと商品** まで
具体化した調合を提案する。消耗品は在庫として管理し、なくなったら通知して Amazon 再購入へつなぐ。

## 対象デバイス
| デバイス | 希釈 | 精油比率の既定 | 備考 |
|---|---|---|---|
| リードディフューザー | 無水エタノール | 精油 20%（15–25%） | スティック本数・交換目安を出力 |
| ネブライザー | なし（原液） | 100% | 運転時間から消費日数を推定 |
| 超音波 | 水（エタノール不使用） | 4 滴 / 100 mL（3–5） | 機器保護のためエタノール不可 |

## 受け入れ基準（Evaluator が検証）
1. **OFNR ウィザード**: O→F→N→R の 4 ステップを順に進み、各ステップで前に戻れる。
   - O: 評価語（例「最悪」「ダメ」）を含むと、観察への言い換えヒントを表示する。
   - F: 満たされている/満たされていない感情をチップで複数選択できる。
   - N: ニーズを 1 つ以上選ばないと次へ進めない。
   - R: デバイス・容量・在庫優先の有無を選ぶと結果が出る。
2. **結果**: OFNR 要約文、精油 2〜4 種（メーカー・商品・mL・滴数・根拠レベル）、エタノール量、合計が容量と一致（丸め誤差 ±1 滴換算以内）。
3. **安全**: 妊娠中/ペット/小児/てんかん の設定で該当禁忌の精油が除外される。免責文を全ページに表示。
4. **在庫**: 状態 新品 / 使用中 / わからない / なくなった を設定・変更できる。
5. **使用記録**: 調合を「作った」と記録すると在庫が減算され、0 以下で「なくなった」に遷移しダッシュボードに通知が出る。
6. **再購入**: 不足・なくなった品に Amazon リンクを表示。`NEXT_PUBLIC_AMAZON_TAG` 設定時は `tag=` が付与される。
7. **通知**: Web プッシュ購読ができ、日次 Cron で low/unknown/empty を通知（同一品 1 日 1 回まで）。
8. **永続化**: Supabase 設定時はログインユーザー単位（RLS）、未設定時はブラウザ（IndexedDB）に保存。
9. **品質**: lint / typecheck / unit test / build / e2e がすべて成功。

## スコア観点（Evaluator）
- 機能完全性 40% / 調合計算の正確性 25% / NVC の言語品質 15% / アクセシビリティ・モバイル 10% / コード品質 10%
